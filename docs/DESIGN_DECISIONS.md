# Significant design decisions

| Problem                     | Alternatives                                                  | Choice and reason                                                                                                                                | Trade-off / future work                                                                                          |
| --------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| Preserve existing projects  | Replace root; new branch; independent subdirectory            | Build `axiom/` as a standalone Vite package because the root contains unrelated uncommitted work.                                                | The standalone repository now deploys from its root.                                                             |
| Parse a small language      | Parser generator; Pratt parser; recursive descent             | Recursive-descent statements plus precedence-climbing expressions. The grammar is small and the algorithm is teachable.                          | Recovery is intentionally modest. An incremental Lezer grammar would improve editor assistance.                  |
| Represent syntax            | Generic object maps; class hierarchy; tagged union            | Typed Rust enums make compiler passes explicit and retain source spans; TypeScript mirrors display contracts.                                    | Every new node requires updating traversal and semantic/compiler cases.                                          |
| Resolve variable storage    | Dynamic environment maps; reused slots; distinct slots        | Resolve names statically to unique local/global slots. Shadowing is straightforward and runtime lookup is constant-time.                         | Slots are retained until frame end. Add liveness-aware slot reuse only with debugger visibility tests.           |
| Implement execution         | AST interpreter; transpile to JS; bytecode VM                 | Numeric bytecode and an explicit stack VM make evaluation order, jumps and frames inspectable without host execution.                            | More machinery and instruction dispatch overhead. A register VM is a meaningful research comparison.             |
| Implement recursion         | Host recursion; explicit frames                               | CALL/RETURN manage explicit frame arrays, saved PCs and operand stack bases.                                                                     | Depth must be bounded; no tail-call optimization is advertised.                                                  |
| Execute in the browser      | Main thread; external service; worker                         | A dedicated worker compiles and runs locally, yielding between 1,500-instruction chunks. Stop terminates it.                                     | Serialization and startup costs exist. A worker is not an OS sandbox.                                            |
| Prevent stale inspectors    | Shared mutable globals; source hashing; request versions      | Each edited session terminates its predecessor and uses a monotonically increasing version. All compiler/runtime panels consume that generation. | Editing clears old exploration state, deliberately favoring correctness over retaining obsolete displays.        |
| Display an AST              | React Flow; custom SVG; text tree only                        | A compact custom SVG tree avoids another large dependency. A lazily expanded HTML tree supplies a keyboard alternative.                          | The graph caps visible nodes at 300. Edge/layout quality and incremental large-graph navigation can be improved. |
| Source debugger granularity | Instruction-only; full statement records; line spans          | Real instruction stepping plus line/depth-based into/over/out supports useful recursion inspection now.                                          | Multiple statements on one line share a source step. Precise statement-boundary metadata is a future project.    |
| Public docs and SEO         | SPA only; separate Next app; prerender shared content         | A Node build script prerenders the same article data into route directories.                                                                     | No invented domain: canonical URLs/sitemap require VITE_SITE_URL. The studio remains client-rendered.            |
| Typography                  | Hosted web fonts; bundled fonts; system fonts                 | Self-hosted Instrument Sans and IBM Plex Mono establish consistent typography without a font service.                                            | Additional font assets; SIL Open Font License texts are shipped in public/licenses/.                             |
| Benchmark reporting         | Seeded charts; live automatic runs; intentional measured runs | Explicitly run validated inputs with warm-ups, medians, ranges and environment metadata.                                                         | Timing reflects JIT, timer precision and scheduling. No cross-language speed claims.                             |

## Final review approach

Read the implementation as a reviewer: compare grammar, typing, bytecode stack effects and VM transitions; execute boundary cases; inspect real browser states; document known limits. Test failures are investigated as either product bugs or incorrect assertions. No failure is hidden with skipped tests or a fabricated result.

## Rust engine migration

Rust/WebAssembly separates language semantics from the React/TypeScript UI while preserving browser execution and static hosting. The JSON ABI adds startup and serialization costs. The live VM remains in Rust between batches. The original TypeScript engine is preserved as a differential test oracle. A source-digest-checked Wasm artifact avoids requiring Rust on Vercel; CI rebuilds and tests it. This is not a measured performance claim. See MIGRATION.md for compatibility evidence.

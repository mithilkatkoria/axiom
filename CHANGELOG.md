# Changelog

## Language 1.1 and studio 1.1.0 - 5 November 2026

- A six-lesson interactive beginner course at /start, including editable programs, real output checks, hints, worked examples, saved progress and studio handoff.
- A clearer homepage explaining Axiom, its Rust implementation and its visual studio, with project authorship and open-source links.
- Typed string concatenation with +, explicit str(value) conversion, and len(text).
- A bounded CONCAT instruction plus LENGTH and TO_STRING, appended after the original 25 opcode numbers.
- Helpful diagnostic notes in the editor, output panel, Problems panel and beginner course.
- Three new gallery examples and tested solutions for every lesson.
- A readable, prerendered beginner course for visitors with JavaScript disabled.

The Rust engine is version 1.2.0. Existing top-level functions named len or str take precedence over the new helpers. Numeric addition, earlier opcode numbers, language syntax, debugger controls, original examples and compatibility reference remain supported.
